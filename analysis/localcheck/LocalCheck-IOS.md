## What It Is
Native iOS Swift app (SwiftUI) for pickup sports communities (basketball, pickleball). Real-time Supabase backend.

**Core Features:**
- Geolocation check-in at courts
- ELO ranking system (competitive fairness)
- Game scheduling & invites
- Court crowdsourcing (Mapbox)
- Real-time player availability

## The Tech Stack
- **Frontend:** SwiftUI (modern iOS)
- **Backend:** Supabase (real-time Postgres)
- **Maps:** Mapbox integration
- **Auth:** Firebase Auth
