# Hingesight — Dating Data Analytics

**Repo:** agenticjess-star/DatingData  
**Live:** Not publicly deployed  
**Score:** 4.3/5  
**Category:** Dating Analytics

## What It Is
Full-stack, mobile-first web app that parses your personal Hinge data export and surfaces:
- AI-powered insights (conversation patterns, interaction trends)
- Gamified achievements (milestones, stats)
- Analytics on your dating journey
- Privacy-first: data stays in your own account

## The Tech
- **Backend:** Express (70 deps), REST API
- **Frontend:** React/Vite, mobile-first responsive design
- **Data:** Hinge API integration, personal data export parsing
- **Vision:** ElevenLabs integration (voice features possibly)

## Strengths
✓ Fills real gap: dating apps generate data, but no one analyzes it  
✓ Privacy-forward (no third-party data sharing)  
✓ Gamification keeps users engaged  
✓ Mobile-first design is polished  
✓ Can be positioned as "Spotify Wrapped for your dating life"

## Gaps
