## What It Is

A federated agent framework for high-quality client acquisition campaigns. Design philosophy:
- **No theater** — Agents execute real work or don't run
- **Auditor owns approval** — Final gate is a human-verified Vercel deployment (byte-count validation)
- **Vertical library** — Each approved build gets saved to `/verticals/{type}/` to compound efficiency
- **Portable skills** — All logic as clean SKILL.md + scripts (Hyperagent + consensus format)

**Core agents:**
- Orchestrator — routes tasks + maintains shared ledger
- Builder — runs design + deploy
- Auditor — runs audit + live verification + sign-off

**Connected services:** GitHub + Vercel (verified deploys)
