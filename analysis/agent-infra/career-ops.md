## What It Is (the tool itself)

A Claude Code-powered job search pipeline:
- **A-F scoring** across 10 weighted dimensions per job offer
- **ATS PDF generation** — tailored CVs per JD
- **Playwright scraping** — Greenhouse, Ashby, Lever, company pages
- **Batch processing** — 10+ offers evaluated in parallel via sub-agents
- **Go TUI dashboard** — track all applications, statuses, pipeline state
- **Interview story bank** — accumulates STAR+R stories across evaluations
- **Data contract** — structured JSON schema for all tracker data

Stack: Node.js, Go, Playwright, Claude Code, TypeScript
