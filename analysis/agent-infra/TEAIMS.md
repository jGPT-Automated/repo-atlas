## Verdict Upfront

**TEAIMS is a production-grade multi-agent orchestration system for startup launch automation.**

This is not a toy project. It's a fully specified 9-agent "startup crew" that takes a raw idea through market validation → product design → architecture → implementation → security audit → growth strategy → compliance → launch. Each agent has explicit roles, red lines, tools, constraints, and HITL (human-in-the-loop) checkpoints.

The system implements adversarial debate between agents before decisions are finalized, persistent decision logging, and a context file system (Soul.md, Skills.md, Judgements.md) that codifies organizational knowledge into reusable rules.

---

## What It Is

**Agent Armory** is Jesse's thesis on how AI teams should work:

Modern AI tools give you one agent with one context window. That's like running a company with one employee who's CEO + CTO + designer + lawyer + accountant. TEAIMS treats agents like a real organization:

- Every agent has a **specialized role** with domain expertise
- Every agent has **red lines** — non-negotiable constraints
- Every agent has **flexible areas** — where they compromise for the team
- Agents **debate each other** in structured rounds before finalizing decisions
- A **human-in-the-loop framework** captures uncertain decisions and codifies judgement into reusable rules
- A **context file system** stores organizational identity — shareable via secure tokenized URLs

## The 9-Agent Elite Squad

Role: Market Research & Validation  
Goal: Validate or kill the idea before any code is written  
Tools: Google Search, web scraping, SimilarWeb, Crunchbase, GetLatka, Reddit, X/Twitter

## Architecture

**Frontend Stack:**
- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui + Framer Motion
- Supabase integration (for state persistence)
- 30+ custom components

**Key Components:**
- `AgentCard.tsx` — agent display with role, constraints, tools
- `AgentDrawer.tsx` — detailed agent editor
- `ExecutionFlow.tsx` — pipeline visualization
- `HITLCheckpoints.tsx` — human review gates
- `AnimatedPipelineFlow.tsx` — real-time agent execution status
- `LangGraphMapping.tsx` — reasoning/debate visualization

**State Management:**
- Supabase for decision persistence
- Context API for UI state
- Real-time subscriptions for agent updates

**Data Model:**
- `Agent` interface with role, persona, goal, mission, tools, rules, constraints
- `StateField` / `StateGroup` for tracking pipeline state
- `ErrorHandler` for failure recovery
- `FailureMode` for documented failure paths
- `FinalOutput` for artifact validation

## Standout Features

1. **Adversarial Debate System**
   - Two agents argue opposite sides of a decision
   - Structured debate rounds before consensus
   - Uncertainty captured and escalated to human

2. **Red Lines + Flexible Areas**
   - Non-negotiable constraints (agent won't cross these)
   - Flexible negotiation areas (where compromise happens)
   - Decision matrix: condition → stack → reason

3. **HITL (Human-in-the-Loop) Checkpoints**
   - Marked on agents that need human judgment
   - Termination rules define when to escalate
   - Quality gates for artifact acceptance

4. **Context File System**
   - Soul.md — organizational identity + values
   - Skills.md — reusable capabilities + prompts
   - Judgements.md — codified decisions (learn from past calls)
   - Shareable via secure tokenized URLs

5. **Detailed Agent Specifications**
   - Each agent has explicit tools, rules, constraints
   - Decision matrices for common scenarios
   - Code examples + output templates
   - Failure modes + recovery paths

6. **Real-Time Visualization**
   - Pipeline flow with agent status
   - Debate transcript view
   - File tree generated by agents
   - Error handling UI

## Technical Implementation

**Data-Driven Design:**
All 9 agents and their specifications are defined in `src/data/specData.ts` as TypeScript constants. This makes the system:
- Version-controllable (check-in agent defs)
- Auditable (see exactly what each agent does)
- Reusable (export and import agent specs)
- Type-safe (full TypeScript coverage)

**Component Architecture:**
- Smart separation of concerns: components for UI, contexts for state, hooks for logic
- Radix UI primitives for accessible UI
- Framer Motion for animated flows
- No external backend required (Supabase handles persistence)

**Integrations:**
- Supabase real-time for multi-user collaboration
- Web scraping + search APIs for research agents
- Document generation for output artifacts
- File system visualization
