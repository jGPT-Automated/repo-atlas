Architecture

Frontend
React 18 · Vite · TypeScript
shadcn/ui + Tailwind CSS. Operator-focused dashboard optimized for time-pressure decision-making.
Data Sources
Polymarket Gamma API · CLOB WS · RTDS WS
Two slug conventions for market discovery. Deterministic epoch-based slugs for 5m/15m/4h. Sub-second WebSocket price feeds.
Analysis Engine
Particle Filter · Monte Carlo
Probabilistic models estimate true probability vs market-implied. Brier scoring for accuracy tracking.
Decision Engine
Spot → Probability → Edge → Action
Four-step operator flow. Each step has explainable conditions. Governance log tracks every decision.
Backend
Lovable Cloud · Supabase Edge
Edge functions handle WebSocket aggregation and market discovery. No standalone server.
Governance
Audit Trail Panel
Every BUY/HOLD/EXIT decision logged with timestamp, conditions, and model edge. Full accountability.

03

The Decision Flow

1. Spot vs Strike
"Is the underlying currently above/below the market threshold?" — The foundational question. Real-time spot price from WebSocket feeds overlaid with the contract strike.
2. Implied Probability
"What is Polymarket pricing for UP vs DOWN right now?" — Market-implied probabilities extracted from order book data across multiple timeframes.
3. Model Edge
"Does filtered probability disagree with market enough to matter?" — Particle filter + Monte Carlo produce a model probability. The gap between model and market = edge.
4. Action
"BUY / HOLD / EXIT with explainable conditions + governance log." — Every action is logged with the full decision chain, timestamp, and conditions for post-hoc analysis.
