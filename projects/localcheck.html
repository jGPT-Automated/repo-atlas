02

Key Features

Court Check-In & Live Map
Full-screen Mapbox map with brutalist court markers. Tap a marker → bottom sheet with live roster. Check in broadcasts your presence and generates a feed event with haptic confirmation.
ELO Ranking System
Real-time ELO with animated odometer-style display. Win/loss counter, win rate percentage, recent match history. Default rating: 1200. Persisted in Supabase profiles table.
Game Run Scheduling
Matchmaking lobby with Team A vs B, ELO balancing, and RSVP. Scheduled games with court availability. 6AM slot rules and run caps configured per court.
Community Feed
Reverse-chronological activity feed (hidden from tab bar). Check-ins, game results, and friend interactions generate automatic feed events.
Court Crowdsourcing
Users add new courts with location, sport type, and verification threshold. Community-verified courts get "confirmed" status when player count reaches threshold.
