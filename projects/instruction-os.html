02

Core Loop

Capture Anywhere
Forward a link or drop text in Telegram → the webhook ingests it without opening a dashboard.
Version Every Instruction
Instructions live as versioned artifacts grouped by topic — a changelog for your rules, not a scrap heap.
Agent-Readable via MCP
Any MCP client can list groups, list instructions, and pull the current production instruction.
Thread Comments
Context threads with comment support so agents can annotate and evolve guidance collaboratively.
